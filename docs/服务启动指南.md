# TARS 服务启动指南（v5.0.x）

> 生产环境见 [操作手册](guides/operations-manual.md) · [deploy/README.md](../deploy/README.md)
> 当前稳定版：**v5.0.3**；开发分支代码 OpenAPI 为 **v5.0.4/v5.0.5**

## 一键准备（稳定版）

```bash
cd /path/to/TARS
git checkout v5.0.3
./scripts/deploy-stable.sh
```

## 开发模式启动

### 后端

```bash
cd backend
source .venv/bin/activate      # 注意：是 .venv，不是 venv
python -m tars.main            # 等效于 uvicorn tars.main:app --host 0.0.0.0 --port 8000
```

> `python -m tars.main` 会自动从 `backend/.env` 加载环境变量。如需自定义端口：
> ```bash
> python -m uvicorn tars.main:app --host 0.0.0.0 --port 8000
> ```

### 前端

```bash
cd frontend
npm run dev    # → http://localhost:5173，API 代理到 8000
```

## 生产模式

```bash
# 后端（单 worker，Insight SSE / 多用户隔离要求）
cd backend && source .venv/bin/activate
python -m uvicorn tars.main:app --host 0.0.0.0 --port 8000 --workers 1

# 前端（构建后由 Nginx 托管 dist/）
cd frontend && npm run build
# Nginx 配置见 deploy/nginx.conf
```

## 强制重启

```bash
# 杀掉旧进程
kill $(lsof -ti :8000) 2>/dev/null; sleep 1
kill $(lsof -ti :5173) 2>/dev/null; sleep 1

# 一键脚本
./scripts/restart-tars-dev.sh
```

## 后台运行

```bash
cd backend
nohup .venv/bin/python -m tars.main --host 0.0.0.0 --port 8000 --workers 1 \
  > /tmp/tars-backend.log 2>&1 &

cd ../frontend
nohup npm run dev -- --host 0.0.0.0 --port 5173 --strictPort \
  > /tmp/tars-frontend.log 2>&1 &
```

## 检查服务

```bash
lsof -i :8000 -i :5173
curl -s http://localhost:8000/health          # → {"status":"ok","version":"5.0.5"}
curl -s http://localhost:8000/docs | head -5  # → OpenAPI 5.0.3/5.0.4
curl -s http://localhost:8000/api/insight/version
```

## 访问地址

| 环境 | 前端 | API |
|------|------|-----|
| 开发 | http://localhost:5173 | http://localhost:8000 |
| Docker | http://localhost:8080 | 经 Nginx 反代 |

## 默认账号

首次启动创建 `admin`，密码见启动日志 — **生产务必改密**。

## 关键配置

- **环境变量**：`backend/.env`（复制自 `.env.example`，配置 LLM API Key）
- **模块开关**：`backend/config/modules.yaml`
- **CORS 白名单**：`TARS_CORS_ORIGINS`（默认 localhost:5173/5174）
- **数据库**：生产 PostgreSQL（`DATABASE_URL`），开发 SQLite（默认）
