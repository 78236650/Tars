# 服务启动指南

## 一键启动（推荐）

### 后端

```bash
cd /Users/daobanxiang/myproject/TARS/backend
.venv/bin/python -m uvicorn tars.main:app --host 0.0.0.0 --port 8000 --reload
```

### 前端

```bash
cd /Users/daobanxiang/myproject/TARS/frontend
npm run dev
```

## 强制重启

### 杀掉旧进程再启动

```bash
# 杀后端
kill $(lsof -ti :8000) 2>/dev/null; sleep 1

# 启动后端
cd /Users/daobanxiang/myproject/TARS/backend
.venv/bin/python -m uvicorn tars.main:app --host 0.0.0.0 --port 8000 --reload

# 另一个终端 — 杀前端
kill $(lsof -ti :5173) 2>/dev/null; sleep 1

# 启动前端
cd /Users/daobanxiang/myproject/TARS/frontend
npm run dev
```

## 后台运行（不占终端）

```bash
# 后端后台运行
cd /Users/daobanxiang/myproject/TARS/backend
nohup .venv/bin/python -m uvicorn tars.main:app --host 0.0.0.0 --port 8000 > /tmp/tars-backend.log 2>&1 &

# 前端后台运行
cd /Users/daobanxiang/myproject/TARS/frontend
nohup npm run dev > /tmp/tars-frontend.log 2>&1 &
```

## 查看日志

```bash
# 后端日志
tail -f /tmp/tars-backend.log

# 前端日志
tail -f /tmp/tars-frontend.log
```

## 检查服务状态

```bash
# 检查端口是否在监听
lsof -i :8000  # 后端
lsof -i :5173  # 前端

# 测试后端 API
curl -s http://localhost:8000/api/modules | python3 -m json.tool
```

## 访问地址

- 前端：http://localhost:5173
- 后端 API：http://localhost:8000
- API 文档：http://localhost:8000/docs

## 默认账号

首次启动自动创建 admin 用户，查看启动日志获取初始密码。

## 常见问题

### 后端启动报错 ModuleNotFoundError

```bash
cd /Users/daobanxiang/myproject/TARS/backend
.venv/bin/pip install -r requirements.txt
```

### 前端启动报错

```bash
cd /Users/daobanxiang/myproject/TARS/frontend
rm -rf node_modules && npm install
```

### 端口被占用

```bash
kill $(lsof -ti :8000) 2>/dev/null
kill $(lsof -ti :5173) 2>/dev/null
```
