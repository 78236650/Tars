# TARS 服务启动指南（v4.3.2）

> 生产环境见 [操作手册](guides/operations-manual.md) · [deploy/README.md](../deploy/README.md)

## 一键准备（稳定版）

```bash
cd /path/to/TARS
git checkout v4.3.2
./scripts/deploy-stable.sh
```

## 开发模式启动

### 后端

```bash
cd backend
source venv/bin/activate   # 或 .venv/bin/activate
python3 -m uvicorn tars.main:app --host 0.0.0.0 --port 8000 --reload
```

### 前端

```bash
cd frontend
npm run dev    # http://localhost:5173
```

## 生产模式

```bash
# 后端（必须单 worker，Insight SSE）
python3 -m uvicorn tars.main:app --host 0.0.0.0 --port 8000 --workers 1

# 前端已构建
cd frontend && npm run build
# Nginx 托管 dist/，见 deploy/nginx.conf
```

## 强制重启

```bash
kill $(lsof -ti :8000) 2>/dev/null; sleep 1
kill $(lsof -ti :5173) 2>/dev/null; sleep 1
# 再按上文启动
```

## 后台运行

```bash
cd backend
nohup venv/bin/python -m uvicorn tars.main:app --host 0.0.0.0 --port 8000 --workers 1 \
  > /tmp/tars-backend.log 2>&1 &

cd frontend
nohup npm run dev > /tmp/tars-frontend.log 2>&1 &
```

## 检查服务

```bash
lsof -i :8000
curl -s http://localhost:8000/docs | head -5   # OpenAPI 4.3.2
curl -s http://localhost:8000/api/insight/version
```

## 访问地址

| 环境 | 前端 | API |
|------|------|-----|
| 开发 | http://localhost:5173 | http://localhost:8000 |
| Docker | http://localhost:8080 | 经 Nginx 反代 |

## 默认账号

首次启动创建 `admin`，密码见启动日志 — **生产务必改密**。
