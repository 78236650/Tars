# 实时录音转写 UI 升级设计

## 问题

当前实现把录音按钮塞在文件上传组件里，没有独立的录音界面：
- 开始/停止录音不明显
- 实时转写文本没有专属显示区域
- 每次录音没有独立的会话概念
- 录音状态和转写结果混在一起

## 设计目标

1. 录音是独立的一级操作，不是文件上传的附属
2. 录音过程中有专属的全屏/半屏面板显示实时转写
3. 每次录音是一个独立会话，有清晰的生命周期
4. 停止后自动保存，可选生成摘要

## 组件拆分

| 组件 | 职责 |
|------|------|
| `AudioUploader.vue` | 仅负责文件上传（保持现有功能，去掉录音按钮） |
| `RecordingPanel.vue` | **新增** 录音面板：开始/停止、实时转写显示、完成后操作 |
| `MeetingView.vue` | 页面容器：切换"正常视图"和"录音面板" |

## RecordingPanel 状态机

```
idle → recording → completed
       ↓
     cancelled (丢弃)
```

- **idle**：显示"开始录音"大按钮
- **recording**：显示录音时长 + 实时转写文本 + 停止按钮
- **completed**：显示完整转写 + 生成摘要按钮 + 返回按钮
