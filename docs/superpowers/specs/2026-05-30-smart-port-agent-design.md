## 二、四大业务域 Agent 详解

### 2.1 计划域 Agents（Plan Domain）

#### 船舶计划 Agent

```
┌─────────────────────────────────────────┐
│  船舶计划 Agent                          │
│                                         │
│  知识：航次时刻表 / 船型参数 / 季节性规律 │
│  技能：                                  │
│    · 48h 预到船预报                      │
│    · 船期冲突检测                        │
│    · 到港时间偏差预警                     │
│    · 月度计划自动编排                     │
│  BI：船舶准点率 / 计划偏差率              │
│  告警：船舶延迟 > 2h → 推企微/飞书        │
└─────────────────────────────────────────┘
```

#### 泊位分配 Agent

```
┌─────────────────────────────────────────┐
│  泊位分配 Agent                          │
│                                         │

│  技能：                                  │
│    · 自动泊位推荐（船型匹配）             │
│    · 泊位冲突检测 + 备选方案              │
│    · 特殊船型（危险品/超大）泊位策略       │
```

## 三、Agent 间协作机制

### 3.1 信息流

```
船舶到港 ──→ 船舶计划 Agent ──→ 泊位分配 Agent ──→ 配载 Agent ──→ 堆场 Agent
                  │                                        │
                  │          ┌─────────────────────────────┘
                  ▼          ▼
              装卸 Agent ← 水平运输 Agent ← 闸口 Agent
                  │
                  ├──→ 危险品 Agent（如有危险品）
                  ├──→ 冷藏箱 Agent（如有冷藏箱）
                  └──→ 商务计费 Agent（作业完成后）
```

### 3.2 协作方式

| 模式 | 场景 | 实现 |
|------|------|------|
| **链式接力** | 船舶→泊位→配载→堆场 | 上游 Agent 产出 → 下游 Agent 消费 |
| **并行协同** | 装卸 + 水平运输 + 闸口 | 各 Agent 独立运行，共享状态 |
| **事件驱动** | 危险品泄漏 → 安全应急 | Channel 推送事件 → 触发 Agent |
| **汇聚分析** | 统计 Agent 汇总全港 | 定时拉取各 Agent 数据 |

## 四、技术实现路径

### 4.1 基于 PortMeta 底盘的 Agent 定义

每个港口 Agent = 一个 PortMeta 租户 + 专属技能包

```
租户: "ship-planning"          ← PortMeta 多租户隔离
  ├── 知识库: 船舶资料/SOP/历史数据
  ├── 技能包: 预到船预报/冲突检测/计划编排
  ├── 记忆: 调度员偏好/常用参数
  ├── BI 数据源: TOS 船舶表
  └── 通道: Web / 企微 / 飞书
```

### 4.2 分阶段落地

```
Phase 1（2 周）: 单 Agent 验证
  └── 堆场调度 Agent（最痛、最独立）

Phase 2（4 周）: 操作域覆盖
  └── 船舶计划 + 泊位分配 + 配载优化 + 闸口

Phase 3（4 周）: 安全域 + 支撑域
  └── 危险品 + 冷藏箱 + 安全应急 + 统计 + 维保

Phase 4（2 周）: 总控 + 联调
  └── 数字孪生总控 + 跨 Agent 协作 + UAT
```

### 4.3 外部系统集成

```
TOS（码头操作系统）     ←→  PortMeta Agent  ←→  企微/飞书/钉钉
  ├─ 船舶表                 ├─ 知识库          ├─ 通知推送
  ├─ 堆场表                 ├─ 技能包          ├─ 审批
  ├─ 闸口表                 ├─ BI 鉴数         └─ 对话
  ├─ 配载表                 └─ 工作流
  └─ 计费表

IoT 平台                ←→  PortMeta Agent
  ├─ GPS/AGV 位置            ├─ 实时监控告警
  ├─ 冷藏箱温度              └─ 异常事件触发
  └─ 岸桥/场桥状态
```
