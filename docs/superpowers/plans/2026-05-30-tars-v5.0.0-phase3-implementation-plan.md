# TARS v5.0.0 Phase 3 — Postgres 并发底座 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans or subagent-driven-development task-by-task.

**Goal:** `DATABASE_URL=postgresql://...` 启动 TARS 主库；SQLite 保留 dev 回退；deploy 锁定 `workers=1`。

**Architecture:** `ConnectionManager` 按 URL 选择驱动；`DbCursor` 统一 `?` 占位符；PG 建表无 FTS5 虚表，记忆检索走 `sql_dialect.fulltext_match_clause` + `pg_trgm`/`to_tsvector`。

**Tech Stack:** psycopg2-binary (已有 requirements)、pytest + `TARS_DATABASE_URL` 可选集成测

**SSOT:** `2026-05-30-tars-v5.0.0-multiuser-design.md` §三 Phase 3
