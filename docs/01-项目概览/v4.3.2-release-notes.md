## 摘要

v4.3.2 在 v4.3.1 上交付两大块：

1. **Superpowers 融合** — Skill 自动路由、Plan 审批门控、Verification Gate（原设计稿 v4.4 → 对齐 v4.3.2）
2. **LLM Wiki + RAG 双通路** — 结构化 Wiki 页与现有向量知识库并存，统一上传入口自动路由

## Superpowers

### Skill 自动路由（M1）
- `triggers` / `skip_when` / `priority` frontmatter
- `SkillRouter` + embedding（bge-small-zh-v1.5）+ eval 门控
- Agent system prompt 注入推荐技能区块

### Plan 审批门控（M2）
- 复杂计划 WebSocket 审批 + checkpoint 断点
- REST：`/api/plans` approve / reject / retry
- 前端 `PlanReviewDialog`

### Verification Gate（M3）
- Skill `verify` 块 + strict/lenient 模式
- `verification_audit` 表 + `GET /api/plans/{id}/verification`

### 联调与收尾（M4）
- 全链路 E2E 测试
- `POST /api/plans/{id}/retry` → `TaskExecutor.resume()`
- 路由采纳率 → `SkillOptimizer` 触发器建议

## Wiki + RAG 双通路

| 能力 | 说明 |
|------|------|
| Wiki 存储 | `backend/tars/wiki/store.py`，`data/wiki/*.md` + `index.md` |
| 路由 | `WikiRagRouter`：小文件/纪要 → Wiki；大 PDF → RAG |
| 编译 | `WikiCompiler` + `WikiEventHandler` 事件驱动 |
| Agent | `read_wiki` / `write_wiki`；system prompt 注入索引摘要 |
| 前端 | 知识库 **Wiki** Tab、`WikiViewer.vue` |
| 上传 | `knowledge` API `target=auto\|wiki\|rag` |

用户指南：[guides/wiki-user.md](../guides/wiki-user.md)

## 配置开关

`backend/config/modules.yaml`：

| 键 | 作用 |
|----|------|
| `skill_routing.enabled` | Skill 自动路由 |
| `plan_gate.enabled` | Plan 审批门控 |
| `verification.enabled` | Verification Gate |

Wiki 随知识库模块加载；数据目录 `backend/data/wiki/` 需部署时持久化。
