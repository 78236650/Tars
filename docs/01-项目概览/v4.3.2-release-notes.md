# TARS v4.3.2 Release Notes — Superpowers Integration

| 项 | 值 |
|----|-----|
| 版本号 | v4.3.2 |
| 类型 | Platform patch（v4.3.x 线） |
| 基于 | v4.3.1 |
| OpenAPI | `backend/tars/main.py` → **4.3.2** |
| InsightForge | **INS-2.1.0**（能力版本不变） |

## 摘要

v4.3.2 将 Superpowers 风格的三项能力并入 v4.3.x patch：**Skill 自动路由**、**Plan 审批门控**、**Verification Gate**。原设计稿目标版本号为 v4.4，已与平台版本对齐为 **v4.3.2**。

## 新增能力

### Skill 自动路由（M1）
- `triggers` / `skip_when` / `priority` frontmatter
- `SkillRouter` + embedding（bge-small-zh-v1.5）+ 50 条 eval 门控
- Agent system prompt 注入推荐技能区块

### Plan 审批门控（M2）
- 复杂计划 WebSocket 审批 + checkpoint 断点
- REST：`/api/plans` approve / reject / retry
- 前端 `PlanReviewDialog`

### Verification Gate（M3）
- Skill `verify` 块 + strict/lenient 模式
- `verification_audit` 表 + `GET /api/plans/{id}/verification`

### 联调与收尾（M4）
- 全链路 E2E 测试
- `POST /api/plans/{id}/retry` → `TaskExecutor.resume()`
- 路由采纳率 → `SkillOptimizer` 触发器建议
- [UPGRADE_GUIDE_v4.3.2.md](../UPGRADE_GUIDE_v4.3.2.md) · [SKILL_AUTHORING.md](../SKILL_AUTHORING.md)

## 配置开关

`backend/config/modules.yaml`：`skill_routing` / `plan_gate` / `verification` 均可独立 `enabled: false` 回滚。
