# TARS v4.1.4 Release Notes — Memory Entity Tree

**发布日期:** 2026-05-19  
**基线:** v4.1.3（分支 `v4.1.1` 开发线）

## 概述

v4.1.4 在记忆管理页新增**实体-centric 记忆树**，按人物、项目等实体浏览记忆，并支持压缩谱系视图与轻量关系图，不替代现有人格 / 近期 / 长期 / 全部 Tab。

## 新增功能

### 后端 API

- `GET /api/memory/tree?view=entity|provenance` — 实体树或压缩谱系树
- `GET /api/memory/tree/search?q=` — 树内搜索与展开路径
- `GET /api/memory/tree/relations?entity_id=` — 实体关系边

### 前端「实体」Tab

- 左树右详情；全部展开 / 折叠 / 刷新
- 实体 | 谱系 分段切换
- 选中实体：摘要 + 关系列表 + SVG 迷你关系图（点击跳转实体）
- 搜索（防抖）；Admin 可带 `user_id` 查看他人树
- 「在长期记忆中管理」跳转长期记忆 Tab 并聚焦分组
- 节点数 >120 时默认仅展开顶层并提示

## 升级说明

```bash
git checkout v4.1.1   # 或已含 d498db4 的分支
# 重启 backend + frontend
cd backend && python -m tars.main
cd frontend && npm run dev
```

无需数据库迁移（只读聚合既有 `memories` / `relations` / core blocks）。

## 测试

```bash
cd backend && pytest tests/test_memory_tree_api.py -q
```

## 已知限制（v4.2+）

- 全屏力导向知识图谱
- 超大树真·虚拟滚动（当前为折叠策略）
