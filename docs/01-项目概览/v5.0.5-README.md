## 关键判断

- 架构骨架是企业级的；卡点在安全缺口、可观测性、运维基建三类硬伤。
- 不做多租户 SaaS、不做多 worker 横向扩展（均为 v5.0 有意约束，非缺陷）。
- 全程最小改动、可验证、可回滚；批次一为上线硬阻塞，最先合入。
