## 概述

v4.2.0 在 v4.1.x 底座与记忆图谱基线之上，聚焦两条主线：

1. **内网数据/分析 Copilot** — 业务用户走 Insight 问数，工程师走 BI，知识库与口径双向联动
2. **完整自进化** — 反馈采集、workspace/skills 写回、eval 验证

**稳定线不受影响**：生产环境可继续使用 `v4.1.2`；本版本合并前请在 `v4.2.0` 分支独立验证。
