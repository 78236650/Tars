# TARS v4.1.1 Release Notes — Experience Layer

**发布日期:** 2026-05-19  
**基线:** v4.1.0 (Skill Ecosystem)

## 概述

v4.1.1 在 v4.1.0 技术基线上补齐**用户可见的体验层**，让 SkillHub、SkillRouter、知识引用等能力在前端可被感知和使用。

## 新增功能

### SkillHub 安装向导
- 安装成功弹出向导：用法说明、示例 prompt、「去试试」快捷入口
- 依赖缺失时可「跳过检查，仍要安装」
- 权限确认独立步骤

### 聊天页已激活技能条
- 每轮对话显示 SkillRouter 匹配到的技能
- 后端 WebSocket `skills_active` 事件实时推送

### 知识引用体验
- 引用格式 `[ref:doc_id|文档标题]`
- 聊天内可点击引用卡片
- 侧边预览面板 + `GET /api/knowledge/ref/{doc_id}`

### 设置页版本升级
- 展示 v4.1.x 完整 Changelog（后续版本见 [v4.1.4 发布说明](./v4.1.4-release-notes.md)）

### 会话稳定性（v4.1.1 patch）
- 切换页面后 WebSocket 消息仍写入全局 store
- `KeepAlive` 缓存 ChatView，流式回复不中断

## 升级说明

```bash
git checkout v4.1.1
# 重启 backend + frontend
```

无需数据库迁移。

## 已知限制（留待 v4.1.2+）

- Curator 待归档 UI / 启动扫描
- Provider 用量 / 记忆导出 Admin UI
- 内置技能目录扩展、Scene Analyzer 深度联动
