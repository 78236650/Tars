| 项 | 值 |

## 摘要

v4.4.0 在 v4.3.4 上交付 **港航物流垂直 + 多 Agent 作业调度 MVP**：

1. **编排记忆层** — 调度任务、子 Agent 产出、协同黑板持久化
2. **港航专家 Agent** — 泊位调度、堆场分配、船务确认（A1/A3/A4）
3. **规则拆解编排** — 关键词识别 → 串并行执行 → 泊位冲突告警
4. **业务向 UI** — 侧栏「作业调度」：快捷场景 / 引导填写 / 自由描述

端到端场景：*「安排 COSCO123 靠 3 号泊位卸 800 箱」* → 自动协调三位专家 → 详情页查看结果与协同摘要。

## 记忆与编排（Phase 0–3）

| 能力 | 说明 |
|------|------|
| 垂直模式开关 | `TARS_MEMORY_COMPRESSOR` 等 env 默认关，代码保留可一行打开 |
| 港航实体 schema | `domain_schema.py`：码头/泊位/船舶/航次/堆场等 type 常量 |
| 编排表 | `agent_tasks` / `agent_task_outputs` / `agent_collaboration_ctx` |
| OrchestrationMemory | 任务创建、产出写入、共享黑板读写 |
| SubAgent 接入 | 子任务产出落库；Handoff 写入 `approval_requests` |
| MultiAgentOrchestrator | 领域记忆注入 + 分阶段执行 |

## 港航 Agent 集群（Phase B–E，MVP）

| Agent | 类型 | 职责 |
|-------|------|------|
| 泊位调度 | `berth` | 靠泊窗口、水深、泊位冲突 |
| 船务确认 | `vessel` | ETA、航次、吃水 |
| 堆场分配 | `yard` | 箱位、堆存计划 |

**v4.5 预留（未实现）：** 岸桥 `crane`、货代 `cargo`、报表 `report`。

## API

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/orchestration/tasks` | 分页任务列表 |
| GET | `/api/orchestration/tasks/{id}` | 任务详情（产出 + 共享黑板） |
| POST | `/api/orchestration/dispatch` | 发起调度 `{ session_id, goal }` |

模块开关：`backend/config/modules.yaml` → `optional.orchestration.enabled: true`。

## 前端

| 入口 | 路径 | 说明 |
|------|------|------|
| 作业调度 | `/orchestration` | 侧栏「作业调度」 |
| 操作模式 | — | 快捷场景 / 引导填写 / 自由描述 |
| 详情抽屉 | — | 专家卡片 + 协同摘要（原始 JSON 折叠） |

角色需含 `orchestration` 模块（内置角色 v4.4.0 已同步；自定义角色在 **系统管理 → 角色模板** 勾选「作业调度」）。

## 配置与环境变量

| 键 | 默认 | 说明 |
|----|------|------|
| `modules.yaml` → `orchestration.enabled` | `true` | 关闭后 API 与路由不注册 |
| `TARS_MEMORY_COMPRESSOR` | `false` | 垂直模式：记忆压缩 |
| `TARS_KB_PROMOTION` | `false` | KB 晋升 |
| `TARS_MEMORY_TREE_BUILDER` | `false` | 实体树构建 |
| `TARS_TURN_PUBLISHER` | `false` | 回合知识发布 |

## 明确不在 v4.4.0

- LLM 自动拆解 goal（MVP 规则拆解，见设计 YAGNI）
- 聊天页一句话触发调度
- 真实 TOS / EDI / 数字孪生对接
- 岸桥 / 货代 / 报表 Agent（v4.5）
