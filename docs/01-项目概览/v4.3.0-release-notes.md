## 修复批次（fix-plan）

本版本合并 v4.2.0/v4.3.0 评审 fix-plan 中的 P1/P2 项：

- **Evolution 闭环（F-01, F-06–F-10）** — workspace 对齐 `~/.tars/agents`、eval gate、prompt 限幅、rollback、insight burst、async ingest
- **安全（F-02, F-03）** — ToolDispatcher fail-closed；审批仅本人或 admin
- **Insight（F-04, F-05, F-14–F-16）** — KnowledgeBridge async；adopt 异步 publish；metric_id 校验
- **Queue（F-11）** — drain 期间保持 session 占用
- **Cron（F-13）** — prompt cron 缺 session_id 失败而非污染 default
- **前端（F-21, Handoff UI）** — 跨会话审批/Handoff 提示；HandoffDialog 审查 UI

**v4.3.2 patch** 已交付 Superpowers 融合（见 [v4.3.2-release-notes.md](./v4.3.2-release-notes.md)）。**v4.3.1 patch** 已交付会议 / 知识库 / BI / INS-2.1（见 [v4.3.1-release-notes.md](./v4.3.1-release-notes.md)）。

遗留 **v4.3.2+**：F-12 出站直调完全迁移（F-15 已以 BackgroundTasks 异步化）。
