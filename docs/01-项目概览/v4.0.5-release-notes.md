## 概述

v4.0.5 在 v4.0.0 底座之上，重点解决 **SkillHub 不可用**、**知识库与 Agent 脱节**、**管理台能力不完整** 三类问题。本版本让 bundled 技能可以本地安装并在对话中生效，打通会议→知识库入库链路，并完善 Admin 用户/角色/审计管理界面。

---

## 一、SkillHub 技能生态（核心）

### 1.1 本地 bundled 技能目录

- 新增 `LocalSkillCatalog`，扫描 `backend/data/skillhub/skills/` 与 `skillhub_catalog.json`
- 重写目录条目，替换原先不可安装的 `tars-official/*` 假仓库 ID
- 支持 **10 个可安装技能**：PDF、GitHub、Excel、浏览器自动化、技能发现、摘要、天气等
- 支持 `bundled/*`（单文件 SKILL.md）与 `package/*`（完整技能目录）两种安装来源

### 1.2 安装器增强

- `SkillInstaller` 支持 **SKILL.md** 格式（Agent Skills 规范），不再仅支持 `skill.yaml`
- 安装后自动注册到 `SkillRegistry` 并启用，清除 manifest 缓存，**无需重启**
- 返回 `usage`、`example_prompt`、`ready` 字段，前端展示安装成功与试用提示
- 修复 GitHub 安装路径：先复制到 `skills/` 再加载，避免临时目录销毁导致失败

### 1.3 Agent 技能上下文注入

- `SkillLoader.get_contextual_skill_injection()` — 根据用户消息关键词匹配 Prompt 技能
- 匹配到的技能注入完整 `prompt_template`，而不只是名称列表
- 渐进披露（全量技能索引）+ 上下文注入（命中技能全文）双层机制

### 1.4 前端 SkillHub Tab

- 「精选」筛选，featured 技能优先排序
- 安装成功展示用法说明与示例对话
- 来源标签与安装状态标注

**涉及文件：**

```

backend/tars/skillhub/installer.py          [增强]
backend/tars/skills/loader.py               [增强]
backend/tars/agent/agent.py                 [增强]
backend/data/skillhub_catalog.json          [重写]

```

## 二、知识库增强

### 2.1 统一检索层

- 新增 `knowledge/access.py` — API、工具、Agent 共用的检索入口
- 新增 `knowledge/sqlite_store.py` — 知识库元数据 SQLite 存储
- 支持按 tenant 检索自有 collection + 共享 default collection

### 2.2 Agent 主动检索

- 每轮对话前自动调用 `search_knowledge()` 预检索相关知识
- WebSocket 推送 `thinking_step: 📚 检索知识库` 进度
- System prompt 注入检索结果，并附带知识库使用规则

### 2.3 knowledge_search 工具

- 工具层接入 `db`，支持 tenant 级 collection 过滤
- 返回结构化结果供 Agent 引用

### 2.4 会议 → 知识库入库

- 新增 `POST /api/meeting/{id}/approve-to-knowledge`
- 转写 + 摘要合并为 Markdown 文档写入知识库
- 前端 `TranscriptionDetail` 支持审批入库操作

**涉及文件：**

```
backend/tars/knowledge/access.py              [新增]
backend/tars/knowledge/sqlite_store.py        [新增]
backend/tars/knowledge/indexer.py             [增强]
backend/tars/tools/builtin/knowledge_search.py [增强]
backend/tars/api/meeting.py                   [增强]
```

## 三、会议助手增强

- 转写任务 stale 恢复（180 分钟超时自动标记失败）
- 摘要生成 API：`POST /api/meeting/summarize`

## 升级指南（v4.0.x → v4.0.5）

```bash
git fetch gitee
git checkout v4.0.5
cd backend && pip install -r requirements.txt
cd ../frontend && npm install && npm run build
# 重启后端即可，bundled 技能无需额外配置
```

**可选：** 部署 SearXNG 以启用内网 web_search：

```bash
cd deploy/searxng && ./start.sh
```
