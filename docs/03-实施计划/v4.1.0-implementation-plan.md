# TARS v4.1.0 执行计划 — Skill Ecosystem

> **For agentic workers:** 推荐使用 superpowers:subagent-driven-development 或 executing-plans 按 Task 逐步执行。步骤使用 `- [ ]` 跟踪进度。

**Goal:** 让 SkillHub 技能「装了就能用」，SkillRouter 接入主流程，多租户技能隔离，模块流水线闭环。

**Architecture:** 三源 SkillHub（bundled + skills.sh + GitHub）→ SkillInstaller → tenant-scoped SkillLoader → SkillRouter → Agent prompt 注入。

**Tech Stack:** Python 3.11+, FastAPI, Vue 3 + TypeScript, SQLite, YAML config

**Dependencies:** v4.0.0 Hardened Base 已完成

**预计工期:** 6–8 周（Phase 3/4 可并行）
