# TARS Tools 管理中心设计方案

## 1. 概述

### 1.1 项目背景
TARS Agent 需要一个统一的工具/技能管理中心，让用户可以方便地：
- 查看和管理所有内置工具和用户技能
- 了解每个工具的功能和使用方法
- 配置工具参数
- 添加新的技能

### 1.2 设计目标
- 提供直观的卡片式界面
- 支持技能的完整生命周期管理
- 兼容 SkillsHub 功能（技能导入/导出）
- 与现有 Models、Settings 页面风格一致

---

## 2. 功能需求

### 2.1 技能分类
| 分类 | 说明 | 示例 |
|------|------|------|
| 内置工具 | 系统预置的核心工具 | terminal, file, browser, web, cronjob |
| 用户技能 | 用户自行添加的技能 | custom_api, data_processor |

### 2.2 核心功能

#### 2.2.1 技能列表
- 卡片网格布局展示所有技能
- 显示技能图标、名称、状态
- 支持筛选：全部 / 内置 / 用户 / 已禁用
- 支持搜索：按名称搜索技能

#### 2.2.2 技能详情（弹窗）
- **介绍**：技能的完整功能说明
- **使用方法**：使用示例和语法
- **配置参数**：可编辑的参数表单
- **操作按钮**：启用/禁用、重置配置，删除

#### 2.2.3 添加技能
支持两种方式：
1. **文件导入**：上传 JSON/YAML/Python 文件
2. **模板创建**：从预设模板生成新技能

#### 2.2.4 技能管理
- **启用/禁用**：开关控制技能状态
- **配置参数**：编辑 JSON 格式的配置
- **重置配置**：恢复到默认设置
- **删除技能**：移除用户添加的技能（内置不可删除）

## 4. 技术设计

### 4.1 页面路由
```
/tools → ToolsView.vue
```

### 4.2 组件结构
```
Views/
  ToolsView.vue              # 主页面
    /components/
      ToolsGrid.vue          # 技能卡片网格
      ToolCard.vue           # 单个技能卡片
      ToolDetailModal.vue    # 详情弹窗
      AddToolModal.vue       # 添加技能弹窗
```

### 4.3 API 接口

#### 获取工具列表
```
GET /api/tools
Response: {
  "tools": [
    {
      "id": "terminal",
      "name": "terminal",
      "icon": "💻",
      "type": "builtin",
      "status": "active",
      "description": "执行系统命令"
    }
  ]
}
```

#### 获取工具详情
```
GET /api/tools/{tool_id}
Response: {
  "id": "terminal",
  "name": "terminal",
  "icon": "💻",
  "type": "builtin",
  "status": "active",
  "description": "执行系统终端命令",
  "usage": "请帮我执行: ls -la",
  "config": {
    "timeout": 60,
    "working_dir": "/home/user"
  }
}
```

#### 更新工具配置
```
PUT /api/tools/{tool_id}/config
Body: { "config": { "timeout": 120 } }
```

#### 启用/禁用工具
```
PUT /api/tools/{tool_id}/status
Body: { "status": "disabled" }
```

#### 添加工具
```
POST /api/tools
Body: {
  "type": "file|template",
  "file": "...",  // 文件导入时
  "template": "api_call"  // 模板创建时
}
```

#### 删除工具
```
DELETE /api/tools/{tool_id}
```

#### 获取工具模板列表
```
GET /api/tools/templates
Response: {
  "templates": [
    { "id": "api_call", "name": "API 调用工具" },
    { "id": "data_process", "name": "数据处理工具" }
  ]
}
```

### 4.4 后端数据结构

```python
class Tool(BaseModel):
    id: str                    # 唯一标识
    name: str                  # 显示名称
    icon: str                  # emoji 图标
    type: ToolType             # builtin / user
    category: str              # 分类
    status: ToolStatus         # active / disabled
    description: str           # 介绍
    usage: str                 # 使用方法/示例
    config: Dict[str, Any]     # 配置参数
    default_config: Dict[str, Any]  # 默认配置
    created_at: datetime
    updated_at: datetime
```

## 5. 内置工具清单

| 工具 ID | 名称 | 图标 | 功能 |
|---------|------|------|------|
| terminal | 终端 | 💻 | 执行系统命令 |
| file | 文件 | 📁 | 读写搜索文件 |
| browser | 浏览器 | 🌐 | 浏览器自动化 |
| web | 网络 | 🔍 | 网络搜索和信息提取 |
| delegate | 委托 | 🤖 | 委派子代理处理任务 |
| cronjob | 定时任务 | ⏰ | 创建和管理定时任务 |

## 6. 技能模板清单

|---------|------|------|
| api_call | API 调用工具 | 调用 REST API 获取数据 |
