# TARS v4.0.0 前端适配设计方案

## 日期: 2026-05-17
## 技术栈: Vue 3 + Pinia + Vue Router + Tailwind CSS (Graphite Amber 深色主题) + WebSocket
## 后端依赖: Phase 1-4 全部 API 已就位
## 设计约束:
- 深色主题：背景 `#0c0b09` / `#14110f`，主色 amber-500，文字 stone-100/200/400
- API 模式：`export const xxxApi = { method: async () => ... }`
- Store 模式：Pinia composition API (`defineStore('name', () => { ... })`)
- WebSocket：wsStore 用 `subscribe(handler)` 订阅模式
- 国际化：所有用户可见文本用 `t('key')` 包裹

## 二、P0: Sidebar 动态菜单

### 需求
根据 `GET /api/modules` 返回的启用状态，隐藏未启用模块的导航项。

### API
```
GET /api/modules
Response: [
  { "name": "core", "enabled": true, "modules": ["agent","tools",...] },
  { "name": "bi", "enabled": false, "description": "BI 工作台" },
  { "name": "meeting", "enabled": false, "description": "会议助手" },
  { "name": "knowledge", "enabled": true, "description": "知识库" },
  { "name": "skillhub", "enabled": true, "description": "SkillHub" }
]
```

### 实现方案

**文件: `frontend/src/api/index.ts`** — 新增：
```ts
export const modulesApi = {
  list: async () => {
    const response = await api.get<ModuleStatus[]>('/modules')
    return response.data
  }
}
```

**文件: `frontend/src/stores/settings.ts`** — 新增：
```ts
// state
const enabledModules = ref<string[]>([])

// action
async function loadModules() {
  const modules = await modulesApi.list()
  enabledModules.value = modules
    .filter((m: any) => m.enabled)
    .map((m: any) => m.name)
}
```

**文件: `frontend/src/components/layout/Sidebar.vue`** — 改动：
```ts
// 模块 → 路由映射
const moduleRouteMap: Record<string, string> = {
  bi: '/bi',
  knowledge: '/knowledge',
  meeting: '/meeting',
}

// 过滤 navItems
const visibleNavItems = computed(() =>
  navItems.filter(item => {
    const mod = Object.entries(moduleRouteMap).find(([_, path]) => item.path === path)
    if (!mod) return true // 核心路由始终显示
    return settingsStore.enabledModules.includes(mod[0])
  })
)
```

模板中 `v-for="item in navItems"` 改为 `v-for="item in visibleNavItems"`。

## 三、P0: 排队状态提示

### 需求
当后端返回 `rate_limited` 错误时，在聊天区域显示排队提示，而非通用错误。

### 后端事件
```json
{ "type": "error", "code": "rate_limited", "message": "系统繁忙，请稍后重试" }
```

### 实现方案

**文件: `frontend/src/stores/wsStore.ts`** — 无需修改 wsStore 本身。

**文件: `frontend/src/components/chat/QueueStatus.vue`** — 新建：
```vue
<script setup lang="ts">
import { ref } from 'vue'
import { useWsStore } from '@/stores/wsStore'
import { useI18n } from '@/i18n'

const wsStore = useWsStore()
const { t } = useI18n()
const isQueued = ref(false)
const queueMessage = ref('')

// 通过 wsStore handler 订阅
wsStore.subscribe({
  onMessage(data: any) {
    if (data.type === 'error' && data.code === 'rate_limited') {
      isQueued.value = true
      queueMessage.value = data.message
      setTimeout(() => { isQueued.value = false }, 5000)
    }
  }
})
</script>

<template>
  <div v-if="isQueued"
    class="flex items-center gap-2 px-4 py-2 mx-4 mb-2 rounded-lg bg-amber-500/10 border border-amber-300/20 text-amber-100 text-sm">
    <svg class="w-4 h-4 animate-spin" viewBox="0 0 24 24" fill="none">
      <circle cx="12" cy="12" r="10" stroke="currentColor" stroke-width="2" opacity="0.3"/>
      <path d="M12 2a10 10 0 0 1 10 10" stroke="currentColor" stroke-width="2" stroke-linecap="round"/>
    </svg>
    <span>{{ queueMessage || t('chat.rateLimited') }}</span>
  </div>
</template>
```

在 ChatView.vue 输入框上方引入此组件。

### 需求
Admin 可查看所有用户记忆统计、查看详情、清空、管理共享记忆。

### API
```
GET    /api/admin/memory/users → [{ tenant_id, memory_count, shared_count }]
GET    /api/admin/memory/users/{id} → [{ id, content, category, scope, ... }]
DELETE /api/admin/memory/users/{id}/purge
POST   /api/admin/memory/shared → { content, category }
DELETE /api/admin/memory/shared/{id}
```

在 MemoryView.vue 中新增 admin tab：

┌─ 我的记忆 ─┬─ 管理面板(admin) ─┐
│                                  │
│  用户列表          记忆详情       │
│  ┌──────────┐    ┌───────────┐  │
│  │ user1 (32)│    │ content.. │  │
