# PPT Generator（PPT 生成）

根据售前方案/需求文档生成完整的演示文稿。

## 输出结构

### 封面页
- 标题、副标题、日期、汇报人

### 目录页
- 章节概览（3-5 个章节，每个带 1 句话简介）

### 内容页（每页格式）
```
## Slide N: 页面标题

**核心要点**
- 要点 1
- 要点 2
- 要点 3

**图表建议**: [具体图表类型 + 用途说明]

**演讲备注**: [50 字以内的口头讲解提示]
```

### 总结页
- 核心价值主张
- 下一步行动建议
- Q&A 提示

## 风格要求
- 商务专业，避免技术俚语
- 每页不超过 5 个要点
- 图表建议具体化（如「柱状图对比成本」）
- 适合口头汇报的节奏
